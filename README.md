# Taller de Ingeniería Informática - Laboratorio Práctico N°2

## Instrucciones para iniciar el proyecto
1. Clonar este repositorio: `git clone https://github.com/KriegerN/taller-lab-2`
2. Ingresar a la carpeta del proyecto.
3. Ejecutar el siguiente comando para construir y levantar los servicios en segundo plano: docker compose up -d --build
4. Acceder a la aplicacion web desde el navegador en http://localhost:8080. o reemplazando localhost por la IP correcta correspondiente.
